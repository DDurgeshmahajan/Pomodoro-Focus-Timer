# Pomodoro Focus Timer

## Short Description
The Pomodoro Focus Timer is a Java application that helps you manage your time more effectively using the Pomodoro Technique. It allows you to break your work into focused intervals, typically 25 minutes, followed by short breaks. After four intervals, you take a longer break. This technique helps improve productivity by reducing burnout and increasing concentration.

## Features
- **Timed Sessions:** Work sessions, short breaks, and long breaks.
- **Start/Resume:** Begin or continue a session.
- **Pause:** Temporarily stop the current session.
- **Reset Session:** Restart the current session.
- **Reset Cycle:** Start a new cycle from the beginning.
- **Clear Screen:** Keeps the display clean and distraction-free.
- **User-Friendly Interface:** Simple commands to control the timer.

## Usage Instructions
1. **Clone the Repository:**
   ```bash
   git clone https://github.com/DDurgeshmahajan/Pomodoro-Focus-Timer.git
   cd Pomodoro-Focus-Timer
   ```

2. **Compile the Java Files:**
   ```bash
   javac Main.java PomodoroManager.java CountdownTimer.java PomodoroSession.java
   ```

3. **Run the Application:**
   ```bash
   java Main
   ```

4. **Control the Timer:**
   - **s**: Start or resume the current session.
   - **p**: Pause the current session.
   - **r**: Reset the current session.
   - **R**: Reset the entire cycle to the beginning.
   - **q**: Quit the application.

## Example/Preview
When you run the application, you'll see a clean interface with the current session type and time remaining. For example:
```
Current Session: Work (Pomodoro 1/4)
Time Remaining: 25:00
```
You can control the timer using the commands provided.
